# Hamburbur
### A Mod Menu for Gorilla Tag

Hamburbur is a simple, clean, and easy-to-use mod menu for Gorilla Tag.  
No clutter. No overcomplication. Just a quality modding experience.

---

## Overview

Hamburbur focuses on simplicity above everything else.  
The goal is to provide a clean and minimal mod menu experience without unnecessary features or visual noise.

---

## Features

- Advanced customization
- AI-powered voice assistant
- Straightforward navigation
- Core quality-of-life features
- No unnecessary bloat

---

## Installation

1. Install BepInEx (5.x recommended).
2. Place `Hamburbur.dll` inside your `BepInEx/plugins` folder.
3. Launch Gorilla Tag.
4. Open the menu in-game using:
   - `Y` (VR)
   - `Tab` or `H` (PC)

---

## Requirements

- Gorilla Tag (Steam VR version (rift is not supported)
- BepInEx 5.x
- Any OS that can support BepInEx and GorillaTag (Windows is needed for Jarvis/Voice Controls)

---

## Hamburbur plugins

Managed hamburbur plugin DLLs can be placed in `<Gorilla Tag>/hamburbur/Plugins`. They are discovered after the menu finishes loading, including when hamburbur is injected after the game has started.

Open **Settings > Plugins** to view discovered plugins. New managed plugins can be enabled, disabled, or reloaded, and each of their mod buttons can be shown or hidden without changing the mod's enabled state. Legacy BepInEx hamburbur plugins are listed as read-only.

The same managed plugin DLL may also keep a BepInEx entry point and be installed normally in `BepInEx/plugins`.
